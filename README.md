# 青蓝账本

青蓝账本是一款本地优先、支持离线使用的中文个人记账与现金流管理 PWA，特别面向收入到账存在延迟、需要严格预留生活费和分期资金的学生。

## 运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产检查：

```bash
npm run typecheck
npm run test
npm run build
```

浏览器打开开发服务器显示的本地地址。支持 PWA 的浏览器会提供“安装应用”入口；首次成功访问后可以离线打开。

## 已实现功能

- 已到账余额、应收工资、未来工资、锁定资金和自由资金严格分离。
- 动态安全线、周预算上限、预算缺口和消费前模拟。
- 支出、收入、退款、转账、借出、收回、工资到账等流水记录。
- 每日考勤、日薪计算、工资结算批次与手动到账确认。
- PS 课程 12 期计划、剩余金额、30/60/90 天压力和付款记录。
- 未来余额的保守/按期到账双场景预测、现金流日历和分类统计。
- 账户管理、JSON 完整备份、JSON 恢复、CSV 流水导出。
- IndexedDB 持久化、深浅色主题、移动端底栏、桌面侧栏、离线 Service Worker。

## 数据模型

业务数据位于 `lib/types.ts`，IndexedDB 表位于 `lib/db.ts`：

- `accounts`：账户和余额快照基准。
- `transactions`：已入账、计划或撤销的流水；金额均为整数分。
- `categories`：可分层的收入/支出分类模板。
- `salaryPlans` / `attendance`：工资计划和每日考勤。
- `installmentPlans` / `installmentItems`：分期合同与每一期状态。
- `reserves` / `budgets`：资金预留、安全线与周预算设置。
- `attachments`：可选本地凭证 Blob。

数据库带 `schemaVersion: 1`，后续版本通过 Dexie migration 升级。

## 核心计算

核心纯函数位于 `lib/calculations.ts`，与界面完全分离：

- 当前可用余额 = 所有账户余额，不含应收工资。
- 应收工资 = 已出勤工资 − 已确认到账工资。
- 动态安全线 = 生活费预留 + 应急金 + 指定期限内未付分期 + 其他预留。
- 当前自由资金 = `max(0, 当前可用余额 − 安全线)`，缺口另行显示。
- 建议周预算 = `min(每周上限, max(0, 可分配资金 ÷ 下次主要收入前周数))`。
- 未来余额 = 当前余额 + 目标日前预计到账 − 目标日前预计支出。

历史第一期 PS 付款标记为 `affectsBalance: false`，因为 ¥1,358.55 是付款后的余额快照，避免二次扣款。转账只在账户间移动资金，不计入收入或支出统计。

## 隐私、备份与恢复

所有财务数据和凭证默认只存于当前浏览器的 IndexedDB，不使用服务器数据库、广告或统计脚本。清除浏览器站点数据会删除账本，请定期在“设置与备份”中导出 JSON。

导入前会显示账户和流水数量，可选择合并或覆盖。覆盖前建议先导出当前数据。CSV 只包含流水字段，不包含图片二进制内容。

## 目录

- `app/`：页面、交互组件和响应式样式。
- `lib/`：类型、示例数据、IndexedDB 和财务计算。
- `tests/`：核心算法与持久化测试。
- `public/`：PWA 清单、图标和离线 Service Worker。
- `.openai/hosting.json`：静态发布配置；D1/R2 均为关闭状态。
